# Prompt packs v1

_Draft 1, 2026-10-17. Source of truth for `content/prompts/*.json`, generated by `npm run prompts:build`. 120 Crew, 120 Couple, six packs of twenty each. Rules: under 90 characters, answerable in one line or one photo, never requires the other person to have done anything, never asks for anything you would not want screenshotted. The creature asks these in its own voice, so no "you two" phrasing that sounds like an app._

Reveal rule: both answer blind, then both answers show side by side. Prompts are served round-robin within a pack, packs rotate daily in the order listed, so a pair sees each pack about once a week.

## Crew
